# 掼蛋课堂

微信原生小程序，用来学掼蛋。小程序名称是 **掼蛋教学**，界面标题用 **掼蛋课堂**。没有后端，内容都在本地。两个主模块：

- **规则学习**：六节短课，配可点的扑克牌示例。
- **进阶提升**：拆牌短文、按难度分的残局，以及本地判题的情景测验。

底部还有 **我的**，用 `wx.setStorage` 记下学过的课、看过的残局和测验最高分。

## 用微信开发者工具打开

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「导入项目」，目录选这个仓库的根目录（能看到 `app.json` 和 `project.config.json` 的那一层）。
3. AppID 使用 `wxfd17bb26e9716ca4`（已写在 `project.config.json`）。用这个小程序的开发者账号登录后再编译。
4. 导入后直接编译。首页是「规则学习」，导航栏标题是「掼蛋课堂」。
5. 模拟器里点底部三个标签走一遍：规则课、进阶文章、残局、测验。测验做完后到「我的」能看到分数；清空记录也在那一页。

基础库按 `project.config.json` 里的 `3.5.5` 准备。开发者工具如果提示基础库过旧，把本地基础库调到 3.x 即可。

## 上传并提交审核

1. 在微信开发者工具打开本项目，确认详情里的 AppID 是 `wxfd17bb26e9716ca4`。
2. 点击工具栏 **上传**，填写版本号和项目备注，上传为开发版本。
3. 登录 [微信公众平台](https://mp.weixin.qq.com/) → **管理** → **版本管理**。在开发版本中选择刚上传的版本，点击 **提交审核**。
4. 审核通过后，在版本管理里点击 **发布**。线上名称以公众平台登记的「掼蛋教学」为准。

## 规则口径

各地牌桌不完全一样。课里固定用一套常见打法，差异写在「规则学习 → 规则口径」：

- 炸弹：四炸 < 五炸 < 同花顺 < 六炸 < 七炸 < 八炸 < 天王炸。
- 还贡：不超过 10，且不能是王或级牌。竞赛里常允许还任意牌。
- 过 A：A 级双上才获胜；没双上就停在 A，不退级。
- 抗贡：进贡方有两张大王则不进贡，改由头游先出。
